# Cadence Client

Cross-platform client for the Cadence app.

## Local Development

### Prerequisites

- Flutter SDK

### First launch

```shell
git clone https://github.com/cadence-muse/client
cd client

flutter pub get

# Run in web (specific port in order to avoid CORS issues)
flutter run --web-port 33721
```
