## Search UI Pattern

**Applies to:** Tracks tab search + Setlists tab search + existing SetlistTrack picker

**Pattern:** Inline `TextField` with search icon prefix (from `add_setlist_tracks_dialog.dart`)

**Behavior:**
- TextField with `decoration: InputDecoration(hintText: ..., prefixIcon: Icon(Icons.search))`
- 300ms Timer-based debounce on `onChanged` callback (D-02)
- Immediate local `setState` for client-side substring filtering (no debounce delay)
- Online gate: only fire network request if `ref.read(isOnlineProvider)` is true
- Offline fallback: render locally-filtered results using case-insensitive substring match on title + artist

**States:**
1. **Empty state** (no results, search query entered): Render localized "No results" message centered in list area
2. **Loading state** (online, debounce timer active): Show full list while request is in-flight; network results replace on completion
3. **Error state** (network request fails): Render error message with retry button; continue showing cached/local list
4. **Populated state** (search matches found): Render filtered/server-returned list normally
5. **Offline state** (no network): Show locally-filtered results only; offline substring filter applies

## Debounce Implementation Details

**Timing:** 300ms (D-02, copied from `add_setlist_tracks_dialog.dart:77`)

**Code Pattern to Reuse:**
```dart
void _onSearchChanged(String value) {
  setState(() => _searchQuery = value);
  _debounceTimer?.cancel();
  if (!ref.read(isOnlineProvider)) return;
  _debounceTimer = Timer(const Duration(milliseconds: 300), () {
    if (!mounted) return;
    ref.read(publicApiProvider).listBandTracks(
      widget.bandId,
      searchQuery: _searchQuery,
    ).catchError((_) => <Map<String, dynamic>>[]);
  });
}
```

**Modifications for Tracks/Setlists tabs:**
- Replace `listBandTracks(widget.bandId, ...)` with `listUserTracks(...)` or `listUserSetlists(...)`
- **CRITICAL D-03 change:** Do NOT discard the `.catchError()` result — render the server results in the displayed list if online
