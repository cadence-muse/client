    Create lib/features/metronome/metronome_dial.dart. Define a top-level pure function
    `int angleToBpm(double degreesFromTop)` -- `degreesFromTop` is already normalized to
    (-180, 180], 0 = 12 o'clock/top, positive = clockwise (the caller computes this from a
    raw dart:math atan2(dy, dx) result via `var degrees = angleRadians * 180 / math.pi +
    90; if (degrees > 180) degrees -= 360; if (degrees <= -180) degrees += 360;` -- do
    this normalization in the widget's gesture handler, not inside angleToBpm, so
    angleToBpm stays a trivial, directly-testable pure function). Inside angleToBpm:
    clamp `degreesFromTop` to [-135, 135] (a 270-degree sweep, leaving a 90-degree dead
    zone centered at the bottom/6-o'clock, per RESEARCH Pitfall 4's wraparound problem --
    anything in the dead zone clamps to whichever of -135/135 it's numerically closer to,
    which `.clamp(-135, 135)` already does correctly for both sides of the raw atan2
    discontinuity, since the caller's normalization maps that discontinuity itself into
    the middle of the dead zone, not at either sweep endpoint); then `final t =
    (clamped + 135) / 270; final bpmFloat = 40 + t * (300 - 40); return
    bpmFloat.round().clamp(40, 300);`.

    Define `class MetronomeDialPainter extends CustomPainter` -- constructor takes `bpm`
    (int), `ringColor`, `numberStyle`, `unitStyle` (resolved outside the painter, since
    CustomPainter has no BuildContext). paint(): draw an outer ring stroke (`ringColor`,
    strokeWidth 4, PaintingStyle.stroke) at the dial's radius; center the BPM number via a
    `TextPainter` using `numberStyle` (Headline Large, weight 700); a second, smaller
    `TextPainter` below it using `unitStyle` (Body Medium) for the "BPM" unit label.
    `shouldRepaint` returns true only if `bpm` changed.

    Define `class MetronomeDial extends StatelessWidget` -- `const
    MetronomeDial({required this.bpm, required this.onBpmChanged, super.key}); final int
    bpm; final ValueChanged<int> onBpmChanged;`. build(): `final diameter =
    math.min(MediaQuery.of(context).size.width * 0.8, 320.0);` -- wrap a `GestureDetector`
    (both `onPanStart` and `onPanUpdate` wired to the same handler, so the dial jumps to
    the touch-down angle immediately AND updates live while dragging, per D-07) around a
    `CustomPaint(size: Size.square(diameter), painter: MetronomeDialPainter(bpm: bpm,
    ringColor: Theme.of(context).colorScheme.outlineVariant, numberStyle:
    Theme.of(context).textTheme.headlineLarge!.copyWith(fontWeight: FontWeight.w700,
    color: Theme.of(context).colorScheme.onSurface), unitStyle:
    Theme.of(context).textTheme.bodyMedium))`, itself wrapped in `SizedBox(width:
    diameter, height: diameter)` so `details.localPosition` in the handler is already
    relative to the dial's own top-left corner. Handler: `dx = details.localPosition.dx -
    diameter / 2; dy = details.localPosition.dy - diameter / 2; angleRadians =
    math.atan2(dy, dx);`, normalize to `degreesFromTop` per the formula above, call
    `onBpmChanged(angleToBpm(degreesFromTop))`.

    In metronome_screen.dart, replace the Plan 18-01 stub -- the standalone `Text('${state.bpm}')`
