## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon button padding, minimal gaps |
| sm | 8px | Compact spacing between inline elements |
| md | 16px | Standard element spacing, padding inside cards |
| lg | 24px | Section padding, major element spacing |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Large section breaks |
| 3xl | 64px | Page-level top/bottom padding |

**Exceptions:** None — strict 8-point scale throughout.

**Metronome-Specific Spacing:**
- Dial container padding: 24px (lg)
- Beat indicator row margin-top: 32px (xl)
- Quick-adjust button gaps from dial: 16px (md)
- FAB offset from dial: standard Material FAB placement (bottom-right corner, 16px from edges)

## Color

| Role | Light Value | Dark Value | Usage |
|------|-------------|-----------|-------|
| **Dominant (60%)** | white (0xFFFFFFFF) | surface (colorScheme.surface) | Screen background, card backgrounds |
| **Secondary (30%)** | surfaceContainerLow (colorScheme.surfaceContainerLow) | surfaceContainer (colorScheme.surfaceContainer) | Dial background container, section cards |
| **Primary Accent (10%)** | colorScheme.primary (green #2D7B4C or auto-derived) | colorScheme.primary (green adjusted for dark) | **Beat 1 indicator dot** (larger, brighter), primary buttons, active/selected states |
| **Neutral Accent (10%)** | outline (colorScheme.outline) or outlineVariant (colorScheme.outlineVariant) | outlineVariant (lighter gray) | **Beats 2–4 indicator dots** (regular size, muted), dial ring/border, disabled states |
| **Destructive** | colorScheme.error (red) | colorScheme.error (red) | Delete/destructive actions only (not used in metronome UI) |

**Accent Reserved For:**
- **Primary (green):** Beat 1 indicator dot, play/pause FAB icon, selected/active UI states
- **Neutral (gray):** Beats 2–4 indicator dots, dial outline/ring, quick-adjust button icons
- **Never:** All interactive elements at once; color is reserved for the specific accented states above

**Specific Metronome Colors:**
- **Dial ring/border:** colorScheme.outlineVariant (neutral gray outline)
- **Beat 1 dot:** colorScheme.primary (green, ~1.5–2x larger than beats 2–4)
- **Beats 2–4 dots:** colorScheme.outlineVariant (neutral gray, smaller)
- **Play/Pause FAB icon:** colorScheme.primary (green)
- **Quick-adjust button icons:** colorScheme.onSurface (default icon color, black/white depending on theme)

## UI Considerations

Applicable state coverage for metronome screen:

| Category | Element(s) | Status | Resolution |
|----------|------------|--------|------------|
| **Playing State** | Dial + Beat indicators + FAB | ✅ Covered | Beats cycle 1→2→3→4→1→... in sequence; beat 1 dot and audio tick accent audibly+visually; BPM number stays fixed; tempo changes take effect immediately on next tick (D-04) |
| **Paused State** | Dial + Beat indicators + FAB | ✅ Covered | No beat indicator pulses; all 4 dots shown in neutral state; BPM number visible; FAB icon = play_arrow; taps start playback |
| **Dragging State** | Dial + BPM number | ✅ Covered | User drags around dial circumference; BPM updates live (D-07) with each angle change; visual angle feedback; no audio ticks during drag |
| **Loading State** | Entire screen | 🧪 Backstop | If audio assets load async, show CircularProgressIndicator + "Initializing metronome..." text (centered); gate play button until ready |
| **Dial Sizing (Responsive)** | Dial container | ✅ Covered | Dial width = min(80% screen width, 320px max); height = width (square dial); centered on screen |
| **BPM Range** | BPM display + Drag bounds | ✅ Covered | Valid range 40–300 BPM (D-06); clamp dragging to this range; quick-adjust buttons respect bounds (e.g., at 300 BPM, "+5" button no-op or disabled) |
| **No-Tempo Track Fallback** | Track Detail metronome entry point | ✅ Covered | Icon button only shown in AppBar.actions if track.tempo != null (D-11); no button at all if tempo is missing; tap opens metronome prefilled with track.tempo |
| **Homepage Tools Entry** | Always defaulted | ✅ Covered | Homepage "Metronome" button always appears and always defaults to 120 BPM (no conditional logic); opens MetronomScreen(bpm: 120) |
| **Overflow/Long Text** | BPM unit label + tooltips | ✅ Covered | BPM unit ("BPM") fits beside/below number in available space; tooltips truncate/wrap naturally in Material tooltip |

## Implementation Notes

**Metronome Screen Structure:**

1. **AppBar:** "Metronome" title, optional refresh/settings icon in actions (discretionary)
2. **Body:** Column layout
   - Dial container (responsive, centered, ~80% width capped at 320px)
   - Beat indicator row (4 dots below dial, D-09)
   - Quick-adjust button row (±1 and ±5 IconButtons flanking dial, D-05)
3. **FAB:** Play/Pause (icon-only, bottom-right Material placement)

**Asset Paths (D-02, D-03):**

- Tick (accent, beat 1): `assets/audio/metronome_accent.wav` (or .mp3)
- Tick (regular, beats 2–4): `assets/audio/metronome_regular.wav` (or .mp3)
- User can drop replacement files at these paths without code changes

**State Management (Riverpod):**

Create a `metronomProvider` that holds:
- Current BPM (StateNotifier<int>)
- Playing state (StateNotifier<bool>)
- Current beat index (0–3, StateNotifier<int>)
- Playback timer logic

**Integration Points:**

1. **Homepage** (`lib/features/home/home_screen.dart`): Add "Tools" section header and "Metronome" button below existing "Quick Actions"
2. **Track Detail** (`lib/features/tracks/track_detail_screen.dart`): Add icon button to AppBar.actions (gated by `tempo != null`), navigate to MetronomScreen(bpm: track.tempo)
3. **Navigation:** Create `lib/features/metronome/metronome_screen.dart` accepting optional `bpm` parameter
4. **pubspec.yaml:** Add `audioplayers: ^5.2.0` (or latest stable)
