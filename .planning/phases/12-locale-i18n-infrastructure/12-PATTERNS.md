**Core provider pattern** (`lib/providers/theme_provider.dart` lines 6-12):

```dart
  @override
  ThemeMode build() => ThemeMode.system;

  void setThemeMode(ThemeMode mode) => state = mode;

```

**Adapt for LocaleController (async + SharedPreferences):**
```dart
@riverpod
class LocaleController extends _$LocaleController {
  static const String _localeKey = 'app_locale';
  
  @override
  Future<Locale> build() async {
    final prefs = await SharedPreferences.getInstance();
    final languageCode = prefs.getString(_localeKey) ?? 'en';
    return Locale(languageCode);
  }

  Future<void> setLocale(Locale locale) async {
    state = AsyncData(locale);
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(_localeKey, locale.languageCode);
  }
}
```

**Key differences from theme_provider:**
- `build()` is async; reads SharedPreferences on app startup, defaults to English
- `setLocale()` handles AsyncValue state (because build is async)
- Returns `Future<Locale>` not `Locale`
- State is `AsyncValue<Locale>` not just `Locale`

### `lib/providers/auth_provider.dart` (reference for D-04 constraint)

**Critical Decision D-04:** Language preference survives logout. `AuthSession.signOut()` must NOT be extended to clear the SharedPreferences language key.

**Current signOut() implementation** (`lib/providers/auth_provider.dart` lines 48-67):
```dart
Future<void> signOut() async {
  if (state.value == null || _loggingOut) return;
  _loggingOut = true;
  try {
    // Best-effort: invalidate the session server-side...
    await ref.read(publicApiProvider).logout();
  } catch (_) {
    // Swallow: see comment above.
  } finally {
    _loggingOut = false;
  }
  await ref.read(tokenStorageProvider).delete();
  await ref.read(cacheServiceProvider).clearAll();
  state = const AsyncData(null);
}
```

**DO NOT MODIFY** to clear SharedPreferences language preference. Add a code comment for future maintainers:
```dart
// D-04: Language preference is a device preference (like system dark mode),
// not account data. It must survive logout/sign-out. Do not extend this method
// to clear SharedPreferences or other local state — only clear auth-specific
// keys (tokens, cache). If new persistent data is added (e.g., UI layout),
// evaluate whether it should survive logout based on the same principle.
```

**Source:** `lib/providers/theme_provider.dart` (proven pattern across all providers in this codebase)

**Apply to:** All new providers (localeControllerProvider follows this exact pattern)

**Pattern:**
```dart
import 'package:riverpod_annotation/riverpod_annotation.dart';

part '{filename}.g.dart';

@riverpod
class {ControllerName} extends _${ControllerName} {
  @override
  {StateType} build() => {defaultValue};

  void {methodName}({StateType} value) => state = value;
  // or for async:
  Future<void> {methodName}({StateType} value) async {
    state = AsyncData(value);
    // persist to storage if needed
  }
}
```

**Why:** 
- `@riverpod` class with `part` codegen is the project standard
- Automatic provider generation via `build_runner`
- Type-safe state with no manual notifier boilerplate
- Consistent pattern for theme, locale, auth, navigation across all providers

### Async State Handling in ConsumerWidget build()

**Source:** `lib/app.dart` (theme binding pattern adapted for async locale)

**Apply to:** All UI widgets that consume async providers (app root, screens with async state)

**Pattern:**
```dart
class {WidgetName} extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final asyncState = ref.watch(asyncProvider);
    
    return asyncState.when(
      data: (value) => {buildWithData},
      loading: () => {loadingWidget},
      error: (error, stack) => {errorWidget},
    );
  }
}
```

**Why:**
- AsyncValue `.when()` cleanly separates loading, data, and error states
- Prevents null-pointer errors from async initial state
- Provides user feedback during slow operations (SharedPreferences read)
- Standard Riverpod pattern

### SharedPreferences Persistence in Riverpod Provider

**Source:** `lib/providers/locale_provider.dart` (new pattern following Riverpod async pattern)

**Apply to:** Any future provider that persists non-secret device state (UI preferences, user settings)

**Pattern:**
```dart
@riverpod
class {Controller} extends _${Controller} {
  static const String _key = '{preferenceKey}';
  
  @override
  Future<{Type}> build() async {
    final prefs = await SharedPreferences.getInstance();
    final stored = prefs.get{Type}(_key) ?? {defaultValue};
    return stored;
  }

  Future<void> set{Type}({Type} value) async {
    state = AsyncData(value);  // Optimistic update
    final prefs = await SharedPreferences.getInstance();
    await prefs.set{Type}(_key, value);
  }
}
```

**Key elements:**
- `build()` is async; reads on app startup
- Static constant for key prevents typos
- Optimistic update: set state immediately, then persist
- No exception handling (SharedPreferences failures are silent by design)

**Why:**
- Survives app restart
- Simple key-value API
- Platform-agnostic (NSUserDefaults on iOS, SharedPreferences on Android)
- Semantically correct for non-secret UI state
