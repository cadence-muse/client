## Specless-probe fallback — dismissed edge categories (not fabricated as truths)

- **empty/null category**: `ApiException.code == null` is not a gap to resolve here — it's D-05's explicit fallback path, already captured as a `must_haves.truths` entry above and proven by this plan's new widget test (unmapped-code case).
- **encoding category**: not applicable. `localizedMessage()` does one exact `switch`/`==` comparison against a fixed 5-value ASCII string enum emitted by the server (`publicapi.yml` `ErrorCode`) and returns a static ARB-defined string — no byte/codepoint/grapheme-cluster ambiguity, no user-supplied text is measured or compared.
- **concurrency category**: not applicable. `localizedMessage()` is a pure, synchronous, side-effect-free function with no shared mutable state; each catch site calls it inline on its own call stack — there is no interleaving or interruption semantics to guarantee.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-01 | Tampering | `ApiExceptionLocalization.localizedMessage` switch | low | mitigate | `switch` has a `default:` branch that always falls through to the raw `message` passthrough for any `code` value outside the 5 known literals — a malicious/misbehaving server cannot force an unhandled-case crash or unintended lookup; no dynamic map/reflection-based key resolution is used. |
| T-14-02 | Information Disclosure | raw `message` passthrough (D-05 fallback) | low | accept | Pre-existing behavior, unchanged scope — every catch site already displayed raw `e.message` verbatim before this phase; this phase only adds a localized override for 5 known codes, it does not change what happens for the fallback path. Server-side response content is out of this phase's control per 14-CONTEXT.md. |

No new authentication, authorization, or data-flow surface is introduced — this phase changes only client-side display text derivation for an existing exception type.
