## Component-Specific Contracts

### TextFormField → Read-Only Date Picker (SETL-13)

**Screens affected:** `create_setlist_screen.dart` (line ~130), `edit_setlist_screen.dart` (line ~151)

**Contract:**
1. Field remains a `TextFormField` with `readOnly: true`
2. No keyboard input allowed (read-only prevents any manual typing)
3. Tapping the field (or surrounding container) opens `showDatePicker()` with parameters:
   - `firstDate`: today − 5 years
   - `lastDate`: today + 2 years
   - `initialDate`: the setlist's existing `eventDate` (parsed via `DateTime.parse()`) when editing; falls back to `today` when creating or editing without a date
4. On picker confirmation, `_dateController.text` is set to the selected date in `YYYY-MM-DD` format
5. A clear (X) `suffixIcon` appears once a date is selected; tapping it:
   - Resets `_dateController.text` to empty string `''`
   - Submits to API as `null` (optional setlist date preserved)
6. `hintText` on the field ("YYYY-MM-DD") remains for a11y but is no longer visible when the field is read-only; may be removed or repurposed in future iterations
7. Localization applies to picker locale (uses system locale or app locale setting from Phase 12)

### IconButton Copy Action (BAND-13)

**Screen affected:** `band_detail_screen.dart` (line ~256)

**Contract:**
1. Copy `IconButton` (icon: `Icons.content_copy`) has `Tooltip(message: bandDetailCopyTooltip)` — always shows "Copy" tooltip
2. `onPressed` callback is always enabled (not gated by `isOnline`)
3. Callback invokes `_copyInviteCode()`, which:
   - Calls `Clipboard.setData(ClipboardData(text: inviteCode))`
   - Shows snackbar with `bandDetailCopiedSnackbar` ("Copied!")
4. No network check, no offline message in tooltip
5. Other band actions (rotate/regenerate/edit/delete/leave/remove-member) retain their existing `isOnline` gates

## Implementation Notes for Executor

1. **Date format round-trip:** API expects `YYYY-MM-DD` (ISO format). Ensure the picker result is formatted to this string before submitting. Use `DateTime.toString().split(' ')[0]` or `DateFormat('yyyy-MM-dd').format(selectedDate)` from `intl` package.

2. **Localization of date picker:** Flutter's `showDatePicker()` respects `Locale.of(context)` — no additional work needed if Phase 12's locale infrastructure is in place.

3. **Testing the date range:** Unit tests should verify:
   - `firstDate` is indeed ~5 years ago
   - `lastDate` is indeed ~2 years from today
   - Dates outside this range cannot be selected
   - Existing dates (when editing) load as `initialDate`
   - Clearing removes the date and submits as `null`

4. **QA-01 verification:** Before marking the phase complete, independently re-verify all 4 gaps in current code (don't trust prior notes). The executor must inspect each artifact and confirm the fix is present.

5. **No behavioral change to other buttons:** Only the copy button loses its `isOnline` gate. All other band actions (rotate, regenerate, edit, delete, leave, remove-member) remain gated behind `isOnline`.
