## Artifacts This Phase Produces

This plan produces no new symbols — it modifies existing display call sites to reuse the pre-existing `DurationFormatting.asMinutesSeconds` extension (`lib/features/tracks/track_formatting.dart`, unmodified, created before this phase) and retires the `asMinutesAndSeconds` extension in `lib/features/setlists/setlist_formatting.dart`. See `11-01-PLAN.md`'s "Artifacts This Phase Produces" for the net-new symbols this phase introduces (`DurationTextInputFormatter`, `parseDurationSeconds()`).

## Coverage Note

No external API integration in this plan (see `../COVERAGE.md`) — this is a pure display-formatting consolidation; no wire-contract fields are read differently.

## Why This Plan Is Wave 1 (Parallel to 11-01, Not Sequenced After It)

This plan is independent of `11-01-PLAN.md`: it reuses `DurationFormatting.asMinutesSeconds`, which already existed in the codebase before this phase and is not modified by either plan. It touches an entirely disjoint set of files (setlist screens/formatting vs. track create/edit forms). There is no new architecture here — `asMinutesSeconds` is already proven in production use on `track_list_screen.dart`, `track_detail_screen.dart`, and `tracks_screen.dart` — so this plan does not need to wait on 11-01's tracer to be proven first; it is a mechanical migration of existing call sites onto an already-battle-tested extension.

<objective>
Every screen that displays a track or setlist duration — track lists, track detail, setlist lists, setlist detail, and setlist totals-with-track-count — uses one consistent mm:ss format. The setlist feature's words-based `"42m 35s"` format (`asMinutesAndSeconds` in `setlist_formatting.dart`) is retired in favor of the track feature's `asMinutesSeconds` extension, per D-01. No special-casing for totals over 60 minutes — plain mm:ss handles it (e.g. a 72-minute setlist shows `"72:15"`).

Purpose: DUR-03 requires the two previously-divergent duration display formats to converge into one, per the user's locked D-01 decision in `11-CONTEXT.md`.

Output: `setlist_formatting.dart`, `setlist_list_screen.dart`, and `setlist_detail_screen.dart` all render duration via `asMinutesSeconds`; `asMinutesAndSeconds` is deleted; zero remaining references to the retired format anywhere in `lib/`.
</objective>
