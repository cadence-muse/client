first). A third task closes every remaining Wave-0 test gap flagged in `08-RESEARCH.md`'s Validation
Architecture section and every `backstop`-tier item in `08-UI-SPEC.md`'s UI Considerations table.

`band_detail_screen.dart`; non-owners never see either control (ROADMAP Phase 8 success criteria).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cadence client -> Cadence API (`POST /api/band/{bandId}/rotate-invite-code`) | Client-submitted request across the network; server is the sole authority on whether the caller is the band owner. |
| Cadence client -> Cadence API (`POST /api/band/{bandId}/transfer-ownership`) | Client-submitted request carrying a target `userId`; server independently validates owner status AND target membership before mutating. |
| BandDetailScreen UI -> local Riverpod state (`BandDetailData`, `BandsListData`) | Client-side patch/invalidate logic trusted to reflect server truth; a bug here misleads the user, but cannot itself grant unauthorized access (server remains authoritative). |
