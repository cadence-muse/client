# Repository Guidelines

## Overview

Cadence — Flutter app for music band repertoire management. Currently at Flutter default-template stage: `lib/main.dart` is unmodified starter code, no custom architecture exists yet.

## Build & Development Commands

```bash
flutter pub get              # Install dependencies
flutter run                  # Run app (device/emulator/simulator required)
flutter analyze              # Static analysis (uses analysis_options.yaml, flutter_lints ruleset)
flutter test                 # Run all tests
flutter test test/widget_test.dart   # Run a single test file
flutter test --plain-name "<test name>"  # Run a single test by name
flutter build apk|ios|web    # Platform builds
```

SDK constraint: Dart `^3.12.2` (see pubspec.yaml).

## Structure

- `lib/` — app source (currently only `main.dart`)
- `test/` — widget/unit tests, mirrors `lib/` layout
- `android/`, `ios/`, `web/` — platform scaffolding (generated by `flutter create`, rarely edited by hand)
- `analysis_options.yaml` — lint rules, extends `package:flutter_lints/flutter.yaml`
